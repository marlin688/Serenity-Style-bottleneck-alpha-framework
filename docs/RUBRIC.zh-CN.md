# Scoring Rubric / 0-50 分评分体系

每个标的按 10 个维度打分，每项 0-5 分，总分 0-50 分。

总分用于快速排序，但不能单独决定仓位类型。框架同时输出三个辅助分数：

| 辅助分数 | 构成 | 用途 |
|---|---|---|
| Quality Score / 30 | 大周期强度、瓶颈强度、验证程度、财务转化、扩产 / 技术路径、风险可控性 | 判断它是不是真瓶颈、能否转成利润 |
| Mispricing Score / 15 | 估值错配、市场未发现程度、催化剂密度 | 判断是否存在未定价 alpha |
| Capital Score / 5 | 资本结构 | 单独检查稀释、债务和融资 overhang |

这样可以区分两类常见情况：

- 高质量但已被充分发现的 core compounder。
- 错配明显但执行和融资风险更高的 high beta bottleneck。

## 1. 大周期强度

| 分数 | 标准 |
|---:|---|
| 0 | 不属于明确大周期 |
| 1 | 有主题联想，但需求弱 |
| 2 | 有行业趋势，但周期不清晰 |
| 3 | 大周期明确，但持续性待验证 |
| 4 | 大周期强，capex / 政策 / 需求明确 |
| 5 | 多年超级周期，需求强且不可逆 |

## 2. 瓶颈强度

| 分数 | 标准 |
|---:|---|
| 0 | 不是瓶颈 |
| 1 | 供应链相关但可替代 |
| 2 | 有一定重要性，但替代供应较多 |
| 3 | 局部瓶颈，下游有一定依赖 |
| 4 | 强瓶颈，替代供应有限 |
| 5 | 下游无法绕开的结构性瓶颈 |

## 3. 验证程度

| 分数 | 标准 |
|---:|---|
| 0 | 无验证 |
| 1 | 只有传闻或概念 |
| 2 | 有少量公开线索 |
| 3 | 有客户、订单、会议或财报语言支持 |
| 4 | 有 backlog、sold out、price hikes、战略投资等强验证 |
| 5 | 多重验证同时成立，且已进入商业 ramp |

## 4. 财务转化

| 分数 | 标准 |
|---:|---|
| 0 | 无收入路径 |
| 1 | 收入路径模糊 |
| 2 | 有收入路径，但规模小或时间远 |
| 3 | 有较清晰 revenue ramp |
| 4 | revenue / margin / backlog conversion 明确 |
| 5 | operating income expansion 已经开始或高度可见 |

## 5. 估值错配

| 分数 | 标准 |
|---:|---|
| 0 | 明显过度定价 |
| 1 | 大部分 bull case 已被定价 |
| 2 | 估值合理但不便宜 |
| 3 | 有一定错配 |
| 4 | 相对 peers / future revenue 明显低估 |
| 5 | 极端错配，市场几乎未理解 |

## 6. 市场未发现程度

| 分数 | 标准 |
|---:|---|
| 0 | 人人都知道的热门股 |
| 1 | 主流市场已充分讨论 |
| 2 | 部分机构覆盖但不深入 |
| 3 | 冷门或非美市场，覆盖不足 |
| 4 | 信息分散，需要供应链 mapping |
| 5 | 极度冷门，机构几乎未进入 |

## 7. 扩产 / 技术路径

| 分数 | 标准 |
|---:|---|
| 0 | 没有扩产或技术路径 |
| 1 | 路径高度不确定 |
| 2 | 有路线图但缺少验证 |
| 3 | 有合作方 / foundry / OSAT / 产能计划 |
| 4 | volume ramp 路径较清晰 |
| 5 | 产能和客户需求都高度可见 |

## 8. 资本结构

| 分数 | 标准 |
|---:|---|
| 0 | 巨额 ATM / 重大稀释红旗 |
| 1 | 稀释风险很高 |
| 2 | 有明显 overhang |
| 3 | 有稀释风险但可控 |
| 4 | 资本结构健康 |
| 5 | 现金充足、低债务、无明显稀释 overhang |

## 9. 催化剂密度

| 分数 | 标准 |
|---:|---|
| 0 | 无催化剂 |
| 1 | 催化剂很远或不明确 |
| 2 | 有少量潜在催化剂 |
| 3 | 有明确财报 / 会议 / 客户节点 |
| 4 | 多个近期催化剂 |
| 5 | 多个强催化剂叠加，且可能改变估值框架 |

## 10. 风险可控性

| 分数 | 标准 |
|---:|---|
| 0 | 风险不可控或 thesis 很脆弱 |
| 1 | 多个高风险叠加 |
| 2 | 高风险，但可小仓观察 |
| 3 | 风险中等，可通过仓位管理 |
| 4 | 风险较可控 |
| 5 | 风险低且 thesis 稳健 |

## 总分解释

| 总分 | 分类 |
|---:|---|
| 40-50 | High-conviction bottleneck candidate |
| 32-39 | Worth tracking / small-to-medium position candidate |
| 25-31 | Watchlist / small satellite only |
| <25 | Avoid or research-only |

## 仓位类型解释

| 类型 | 标准 |
|---|---|
| Core compounder | Quality Score 高、资本结构健康、风险可控。可以是热门股，不要求市场未发现。 |
| High beta bottleneck | Quality Score 合格，Mispricing Score 较高，但执行、融资或波动风险更高。 |
| Watchlist / moonshot | 有大周期或局部瓶颈，但验证、财务转化或风险控制仍不足。 |
| Avoid or research-only | 总分、质量分或资本结构不足，不适合进入候选池。 |
