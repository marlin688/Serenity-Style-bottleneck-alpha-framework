# Bottleneck Alpha Framework / 结构性瓶颈投资框架

## 0. 框架目标

这个框架用于研究一个公司是否处在超级周期里的结构性瓶颈上，并判断该瓶颈是否能转化为收入、利润和估值重估。

它不是为了追逐热点，而是为了回答：

> 这个公司是不是某个大周期里不可绕开的供应链环节？如果是，它能不能把这种不可替代性变成 operating income？

---

## 1. 大周期识别

首先判断标的属于哪个大周期。

常见大周期包括：

- AI compute / ASIC / CPU / GPU
- Memory / HBM / NAND / DRAM
- Optical interconnect / Photonics / CPO / Silicon Photonics
- Power infrastructure / Transformers / Switchgear / Grid
- Advanced packaging / Testing / Inspection / Yield
- National security / CHIPS Act / DoD / Quantum
- Robotics / Space / Critical materials / Rare earths
- Stablecoins / Platform monetization / Retail networks

核心问题：

1. 这个大周期是否由真实 capex、订单、政策或需求驱动？
2. 它是短期新闻，还是 multi-year buildout？
3. 下游客户是否具有强支付能力？
4. 是否出现供需错配？

---

## 2. 供应链分层

不要只说“AI 很强”或“CPO 很强”。必须把公司放到供应链里。

示例：CPO / Silicon Photonics 供应链

| 层级 | 例子 |
|---|---|
| Raw material / feedstock | indium, gallium, germanium |
| Substrate | InP, SOI, glass substrates |
| Epiwafer | InP epiwafer, MBE, MOCVD |
| Foundry | SiPh foundry, III-V foundry |
| Light source | EML, CW DFB lasers, VCSEL |
| Module / transceiver | 800G, 1.6T, LRO, ELS |
| Packaging | optical interposer, fiber attach, alignment |
| Testing / inspection | burn-in, IR leakage detection, failure analysis |
| System / integrator | rack, chassis, cluster |
| End customer | hyperscaler, defense prime, national lab |

关键：同一个主题里，不同层级的毛利率、定价权和估值倍数完全不同。

---

## 3. 真瓶颈判断

一个“真瓶颈”通常满足以下多项：

- 下游无法绕开；
- 替代供应不足；
- 产能 sold out；
- backlog 明显增长；
- 客户长期锁定 capacity；
- 发生 price hikes；
- CEO / conference call 明确说供应紧张；
- 政府 funding 或战略投资验证；
- 供应链多跳映射能到达强下游客户；
- 如果该环节延迟，下游大项目会被拖慢。

不是所有重要环节都是真瓶颈。一个环节如果 BOM 占比很小、替代供应充足、不能涨价、不能转化为 revenue，就不是高质量瓶颈。

---

## 4. 财务转化

这是框架最重要的一步。

供应链重要性必须转化为：

- revenue growth
- gross margin expansion
- operating income
- backlog conversion
- pricing power
- capacity utilization
- long-term contracts
- customer prepayment / NRE

如果只能证明“公司很重要”，但无法证明“公司会赚更多钱”，则只能放进 watchlist。

---

## 5. 估值方法

### 5.1 Capacity × ASP

适合：transceiver、memory、power equipment、产能紧缺行业。

```text
Potential Revenue = capacity × ASP × utilization
```

前提：下游需求远超供应，新增产能几乎都会被买走。

### 5.2 Price hike × margin

适合：memory、材料、化学品、transformers、substrates。

```text
Margin Expansion = price hike impact - raw material / opex increase
```

### 5.3 Peer valuation gap

适合：小公司与同类大公司之间的错配。

问题：如果同类 bottleneck 公司是 $10B、$40B、$50B 市值，而这家公司只有 $300M-$1B，它是否真的应该这么便宜？

### 5.4 Sum-of-parts

适合：多资产平台型公司。

问题：市场是否只看主业务，却忽略了其他高价值资产？

---

## 6. 资本结构检查

再好的 thesis 也可能被稀释毁掉。

必须检查：

- ATM
- convertible notes
- warrants
- SBC
- authorized shares
- lockup
- float dynamics
- debt maturity
- shelf registration
- PIPE terms

一般原则：

- Strategic capital 通常优于 ATM。
- Convertible notes 通常优于 open-market ATM。
- 巨额 ATM 是重大红旗。
- 授权股数大幅增加需要重新评估 thesis。

---

## 7. 仓位类型

### Core Compounder

- 大周期明确；
- 多年 backlog；
- 需求可见；
- 执行风险相对低；
- 资本结构较健康。

### High Beta Bottleneck

- 瓶颈强；
- 市场刚开始理解；
- 波动大；
- 可转化为收入，但执行风险较高。

### Moonshot

- 高不确定性；
- 可能 5x / 10x；
- 也可能大幅回撤；
- 只能小仓位或高风险仓位。

### Hedge

- 用于宏观或组合平衡；
- 不一定是最高成长；
- 可能是黄金、能源、稳定币、现金流公司等。

### Watchlist Only

- 主题有趣；
- 验证不足；
- 财务转化不清晰；
- 估值已过度提前定价。

---

## 8. 退出或降级条件

出现以下情况需要重新评估：

- thesis 被客户、技术路线、财报或供应链验证否定；
- 大客户没有放量；
- qualification 失败；
- 竞争对手拿走关键设计；
- 巨额稀释；
- management 失信；
- backlog 无法转收入；
- price hikes 不成立；
- 只是战略重要，财务不转化；
- 宏观风险导致必须降杠杆。

---

## 9. 研究者纪律

1. 不把供应链重要性直接等同于股票回报。  
2. 不因为 crowded 就自动看空。  
3. 不因 TA 替代基本面。  
4. 不忽略 dilution。  
5. 不把 non-GAAP 当成真实利润。  
6. 不用当前收入否定未来 volume ramp，但也不凭空想象 ramp。  
7. 不追逐每一个新闻周期里的新 bottleneck。  
8. 先建立 conviction，再承受波动。  
9. 不用杠杆硬扛高 beta 小盘。  
10. 任何 thesis 都必须列出 bear case。
